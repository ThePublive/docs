Publive supports editorial workflows for content governance.

**Content Workflows** is the dashboard feature for building named review stages per content type, with an enforced publish gate. See the [Content Workflows overview](/dxp/documentation/content-workflows/overview).

The guides below cover the status-based flow, where content moves through `Approval Pending` using the CMS API. It applies to content types that do not use a Content Workflow.

## Availability

The status-based flow below is available on the **Custom Enterprise** plan only.
